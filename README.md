# Name_Battle

## 概要
高田村で遊んでいた「お名前バトル」をGoogleGeminiを使って作成しました。

## 使用言語
- HTML

## 使い方
以下URLにアクセスする。
https://ratekocha.github.io/Name_Battle/

UI上部で作成する名前の文字数、対戦人数、パスの回数の設定が可能です。
UI下部の文字を引くを押すことで1文字目が表示されます。
プレイヤー1の枠内を選ぶことでターンがプレイヤー2に移行しますので
文字を引くでプレイヤー2の文字を表示してください。
これをすべてのプレイヤーのすべての枠が埋まるまで順番に行い、
一番かっこいい/かわいい名前をみんなで選びましょう。
